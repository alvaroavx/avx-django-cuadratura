# Dirección visual: oficina tributaria serena

La interfaz usa orden, jerarquía y trazabilidad para reducir ansiedad sin imitar un portal estatal. La barra superior identifica Cuadratura, usuario y rol. El contexto persistente muestra contribuyente, RUT y período. Breadcrumb, navegación lateral y menú móvil mantienen ubicación y secciones visibles.

Los tokens principales son azul estructural `#073B5C`, azul de acción `#006FAE`, texto `#17212B`, fondo `#F4F6F7`, superficie blanca, borde `#CBD5DC` y acento naranja `#D95016`. El naranja se limita a foco y detalles. Montos usan números tabulares, texto base de 16 px, controles de al menos 44 px y las tablas conservan desplazamiento horizontal en móvil.

La pantalla mensual prioriza recibido, documentado y diferencia; después muestra afecto, exento e IVA, excepciones y finalmente la tabla operativa. Los estados combinan texto, símbolo y color. Esto implementa una base accesible, pero no constituye ni declara conformidad WCAG formal sin una auditoría específica con tecnología asistiva y pruebas de contraste.
